# LostLink

> 状态：首页只读列表已接入 FastAPI 与 MySQL；发布、登记、举报、匹配、注册、个人页和管理端目前包含前端演示
>
> 前端最后验证：2026-10-02；后端与 MySQL 联调记录：2026-09-30

LostLink 是面向校园失物招领场景的软件工程课程项目。首页通过 FastAPI 和 MySQL 查询失物、拾物记录；点击卡片进入独立详情页。发布失物、登记拾物、举报和匹配通知已有可操作的浏览器本地流程；注册表单、个人页与管理员控制台提供界面或开发预览。真实认证、个人数据、管理操作、发布写入、真实匹配和通知服务尚未接入。

项目希望把失物、拾物信息的发布、检索、匹配和状态跟踪集中到一个协作流程中，减少信息分散和重复沟通。当前产品范围仍处于团队确认阶段，需求草案见 [docs/product/requirements.md](docs/product/requirements.md)。

## 当前状态

已实现：

- 基于 Vue 3、TypeScript 和 Vite 的可运行前端工程。
- 首页关键词搜索，以及类别、校区、时间和记录类型筛选。
- 东丽校区北区/南区二级筛选，以及宁河校区整体筛选。
- 记录卡片、空结果、独立详情页、举报提交页和响应式布局；举报记录只保存在浏览器。
- 发布失物、登记拾物共用前端表单，支持校验、草稿和本地图片预览；匹配通知支持筛选、已读、候选详情及确认/拒绝演示。
- 登录入口页与注册表单，支持必填、确认密码一致性校验和密码显示/隐藏；提交明确提示服务未接入，不创建账户。
- “我的”页面开发预览，包含用户摘要、失物/拾物切换、状态筛选、分页与只读详情。
- 管理控制台开发预览，包含数据概览、举报审核、用户管理、只读审计日志和匹配校准版本管理。
- 基于 Vue Router 的统一页面导航、独立管理布局及窄屏适配。
- FastAPI 应用入口、健康检查、统一错误响应和 OpenAPI 文档。
- 使用 SQLAlchemy 查询 MySQL 的 `GET /api/v1/items` 筛选与分页接口。
- MySQL 8.4 本地容器配置和首个 Alembic migration。
- 前端接口、本地表单及状态存储单元测试，以及后端代码检查、接口测试和可选 MySQL 集成测试。

尚未实现：

- 用户认证、服务端发布与编辑、真实匹配与通知、服务端图片上传和认领归还。
- 当前用户、个人记录、退出登录、物品归属与版本控制，以及记录状态更新接口。
- 管理统计、举报处理、用户限制、审计查询、校准任务和版本审核/启用/回滚接口。
- 浏览器端自动化测试，以及发布、认证和完整业务流程的服务端测试。

个人页和管理端默认展示服务未接入提示。只有在开发预览中主动打开演示数据，才会展示虚构记录和固定指标；真实退出、处罚、评估和版本变更等操作不可执行。演示数据仅在开发环境动态加载，不作为真实身份、权限或 API 契约。

## 页面入口

以下路径附在前端服务地址之后，例如 `http://127.0.0.1:5173/register`。

| 路径 | 当前行为 |
| --- | --- |
| `/` | 首页，查询真实物品接口 |
| `/publish/lost`、`/publish/found` | 发布失物与登记拾物的本地演示 |
| `/notifications` | 本地匹配通知演示 |
| `/login`、`/register` | 登录说明与注册表单；真实认证暂未开放 |
| `/my` | 因缺少会话确认能力，转入登录页并说明依赖 |
| `/admin/{section}` | 因缺少认证及管理资格契约，统一转入登录页 |
| `/my-preview` | 仅开发环境提供个人页预览 |
| `/admin-preview/{overview,reports,users,audit,calibration}` | 仅开发环境提供五个管理模块预览 |

开发预览入口位于登录页。生产环境不提供这些预览入口或页面；当前所有真实管理地址均被阻止，不能据此宣称已完成管理员与普通用户的权限区分。

## 快速开始

首页真实数据查询需要已启动的 FastAPI 和 MySQL；发布、登记、匹配、注册界面和开发预览可单独查看。当前锁定的 Vite 6.4.3 要求 Node.js 18、20 或 22 及以上版本，仓库记录的已验证环境为 Node.js 24.14.1 和 npm 11.11.0。需要真实首页数据时，先按 [backend/README.md](backend/README.md) 启动数据库、执行迁移和演示数据脚本。

在仓库根目录使用 Windows PowerShell 执行：

```powershell
cd frontend
npm.cmd install
Copy-Item .env.example .env
npm.cmd run dev
```

启动成功后，以终端显示的地址为准，通常是 `http://127.0.0.1:5173/`。发布、登记、匹配、登录注册和开发预览不依赖后端；首页在后端不可用时会显示连接错误和重试入口。停止服务时在终端按 `Ctrl+C`。

## 检查与验证记录

以下命令在 `frontend/` 目录执行，按改动范围选择；生产构建在交付或相关配置变更时执行：

```powershell
npm.cmd test
npm.cmd run type-check
npm.cmd run build
```

`test` 运行现有 Vitest 接口层测试，`type-check` 检查 Vue/TypeScript 类型，`build` 执行类型检查并生成 `frontend/dist/`。`dist/` 只是本地产物，不提交到 Git。

2026-10-02 合并后验证结果：5 个测试文件中的 14 个测试通过，类型检查与生产构建通过。

如果 PowerShell 提示禁止运行 `npm.ps1`，请使用上述 `npm.cmd` 命令，无需修改系统执行策略。
