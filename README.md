# LostLink

> 状态：首页只读查询链路已实现；注册、个人页和管理端界面已补充，认证与写入接口待接入
>
> 最后代码与文档核对：2026-10-01（本次未重新运行服务或测试）

LostLink 是面向校园失物招领场景的软件工程课程项目。当前已实现从 Vue 首页经 FastAPI、SQLAlchemy 查询 MySQL 的只读链路，支持失物和拾物记录的搜索、筛选、分页与详情查看。前端已补充注册表单、“我的”页面及管理员控制台的开发预览；真实注册登录、个人数据和管理业务接口尚未实现，页面演示不代表业务联调完成。

项目希望把失物、拾物信息的发布、检索、匹配和状态跟踪集中到一个协作流程中，减少信息分散和重复沟通。当前产品范围仍处于团队确认阶段，需求草案见 [docs/product/requirements.md](docs/product/requirements.md)。

## 当前状态

已实现：

- 基于 Vue 3、TypeScript 和 Vite 的可运行前端工程。
- 首页关键词搜索，以及类别、校区、时间和记录类型筛选。
- 东丽校区北区/南区二级筛选，以及宁河校区整体筛选。
- 记录卡片、空结果、详情弹窗和响应式布局。
- 登录入口页与注册表单，支持必填、确认密码一致性校验和密码显示/隐藏；提交明确提示服务未接入，不创建账户。
- “我的”页面开发预览，包含用户摘要、失物/拾物切换、状态筛选、分页与只读详情。
- 管理控制台开发预览，包含数据概览、举报审核、用户管理、只读审计日志和匹配校准版本管理。
- 基于 hash 的页面导航、独立管理布局及窄屏适配；未引入 Vue Router 或全局认证 Store。
- FastAPI 应用入口、健康检查、统一错误响应和 OpenAPI 文档。
- 使用 SQLAlchemy 查询 MySQL 的 `GET /api/v1/items` 筛选与分页接口。
- MySQL 8.4 本地容器配置和首个 Alembic migration。
- 前端 API 层单元测试，以及后端代码检查、接口测试和可选 MySQL 集成测试。

尚未实现：

- 用户认证、失物/拾物发布与编辑、匹配通知和文件上传。
- 当前用户、个人记录、退出登录、物品归属与版本控制，以及记录状态更新接口。
- 管理统计、举报处理、用户限制、审计查询、校准任务和版本审核/启用/回滚接口。
- 管理动作及权限、用户限制影响范围、校准类别/时间/状态/指标等正式契约。
- 可重复运行的浏览器端自动化测试套件，以及真实认证、权限和完整写入流程验证。已有浏览器操作验证记录见下文。

个人页和管理端默认展示服务未接入提示。只有在开发预览中主动打开演示数据，才会展示虚构记录和固定指标；真实退出、处罚、评估和版本变更等操作不可执行。演示数据仅在开发环境动态加载，不作为真实身份、权限或 API 契约。

## 页面入口

以下路径附在前端服务地址之后，例如 `http://127.0.0.1:5173/#/register`。

| 路径 | 当前行为 |
| --- | --- |
| `/` 或 `/#/` | 首页，查询真实物品接口 |
| `/#/login` | 登录入口与注册链接；真实登录暂未开放 |
| `/#/register` | 注册表单；校验通过后仍提示注册服务未接入 |
| `/#/my` | 因缺少会话确认能力，转入登录页并说明依赖 |
| `/#/admin`、`/#/admin/{overview,reports,users,audit,calibration}` | 因缺少认证及管理资格契约，统一转入登录页 |
| `/#/my-preview` | 仅开发环境提供个人页预览 |
| `/#/admin-preview/{overview,reports,users,audit,calibration}` | 仅开发环境提供五个管理模块预览 |

开发预览入口位于登录页。生产环境不提供这些预览入口或页面；当前所有真实管理地址均被阻止，不能据此宣称已完成管理员与普通用户的权限区分。

## 快速开始

首页真实数据查询需要已启动的 FastAPI 和 MySQL；注册界面和开发预览可单独查看。当前锁定的 Vite 6.4.3 要求 Node.js 18、20 或 22 及以上版本，仓库记录的已验证环境为 Node.js 24.14.1 和 npm 11.11.0。需要真实首页数据时，先按 [backend/README.md](backend/README.md) 启动数据库、执行迁移和演示数据脚本。

在仓库根目录使用 Windows PowerShell 执行：

```powershell
cd frontend
npm.cmd install
Copy-Item .env.example .env
npm.cmd run dev
```

默认地址为 `http://127.0.0.1:5173/`，实际端口以终端输出为准。打开该地址即可查看首页，并从登录页进入注册或开发预览。后端未启动时首页会显示连接失败和重试提示。停止服务时在终端按 `Ctrl+C`。

## 检查与验证记录

以下命令在 `frontend/` 目录执行，按改动范围选择；生产构建在交付或相关配置变更时执行：

```powershell
npm.cmd test
npm.cmd run type-check
npm.cmd run build
```

`test` 运行现有 Vitest 接口层测试，`type-check` 检查 Vue/TypeScript 类型，`build` 执行类型检查并生成 `frontend/dist/`。`dist/` 只是本地产物，不提交到 Git。

仓库已有验证记录：

- 首页只读链路及后端验证情况见 [前端说明](frontend/README.md) 和 [后端说明](backend/README.md)。
- [个人页验证记录](frontend\tmp\personal-page-verification.md)（2026-09-30）：记录类型检查、构建、个人页预览、导航与响应式验证；真实登录和个人数据流程未验证。
- [管理员页面验证记录](frontend\tmp\admin-page-verification.md)（2026-10-01）：记录类型检查、生产构建、管理端五页演示、生产预览隔离、键盘操作和窄屏验证；真实管理员权限、会话及管理接口写入未验证。
- 部分首页回归使用明确标注的临时测试数据，不能视为真实后端联调证据。

如果 PowerShell 提示禁止运行 `npm.ps1`，请使用上述 `npm.cmd` 命令，无需修改系统执行策略。
