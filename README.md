# LostLink

> 状态：认证、物品、图片、举报、匹配通知与管理控制台已完成前后端联调
>
> 前端、后端与 MySQL 联调记录：2026-10-06

LostLink 是面向校园失物招领场景的软件工程课程项目。前端已经接入 FastAPI 和 MySQL，支持认证、物品与图片发布、个人管理、举报审核、候选匹配通知和管理员工作流。

项目希望把失物、拾物信息的发布、检索、匹配和状态跟踪集中到一个协作流程中，减少信息分散和重复沟通。当前产品范围仍处于团队确认阶段，需求草案见 [docs/product/requirements.md](docs/product/requirements.md)。

## 当前状态

已实现：

- 基于 Vue 3、TypeScript 和 Vite 的可运行前端工程。
- 首页关键词搜索，以及类别、校区、时间和记录类型筛选。
- 东丽校区北区/南区二级筛选，以及宁河校区整体筛选。
- 记录卡片、空结果、独立详情页、真实举报提交和响应式布局。
- 发布失物、登记拾物共用前端表单，支持校验、本地草稿、最多三张图片上传并写入真实后端。
- 账号注册、登录、会话恢复、受保护路由和退出登录，并在当前标签页保存 Bearer 会话。
- “我的”页面包含真实用户摘要、个人记录筛选与分页、编辑、找回/归还和关闭操作。
- 管理员控制台包含真实数据概览、举报审核、用户限制/恢复、只读审计日志和匹配校准版本管理。
- 基于 Vue Router 的统一页面导航、独立管理布局及窄屏适配。
- FastAPI 应用入口、健康检查、统一错误响应和 OpenAPI 文档。
- 使用 SQLAlchemy 查询 MySQL 的 `GET /api/v1/items` 筛选与分页接口。
- 后端账号注册、登录、注销和当前用户接口，以及 Bearer 会话、登录失败锁定和角色/归属权限守卫。
- 后端物品详情、发布、个人记录、编辑和状态更新接口，并记录不可变状态审计。
- MySQL 8.4 本地容器配置和四份 Alembic migration。
- 前端接口、本地表单及状态存储单元测试，以及后端代码检查、接口测试和可选 MySQL 集成测试。

后续范围：

- 校园统一身份、密码找回和完整认领/归还身份核验流程。
- 对象存储、异步任务、站外通知以及基于真实标注样本的高级匹配训练。
- 可重复执行的浏览器端自动化测试；当前完整认证、发布、编辑和退出流程已做人工浏览器联调。

个人页和管理端均使用真实账号与服务端数据；所有管理写操作要求管理员角色并记录理由和审计日志。

## 页面入口

以下路径附在前端服务地址之后，例如 `http://127.0.0.1:5173/register`。

| 路径 | 当前行为 |
| --- | --- |
| `/` | 首页，查询真实物品接口 |
| `/publish/lost`、`/publish/found` | 登录后向后端发布真实失物或拾物记录 |
| `/notifications` | 登录后查看真实候选匹配通知并提交反馈 |
| `/login`、`/register` | 真实账号登录与注册 |
| `/my` | 登录后查看和管理自己的记录 |
| `/admin/{section}` | 管理员工作台，提供概览、举报、用户、审计和校准模块 |
| `/admin-preview/{section}` | 兼容旧链接并重定向到真实管理地址 |

前端路由守卫只改善导航体验，管理员与普通用户的权限区分最终由后端逐个接口验证。

## 快速开始

全部真实业务流程都需要已启动的 FastAPI 和 MySQL。当前锁定的 Vite 6.4.3 要求 Node.js 18、20 或 22 及以上版本。启动前先按 [backend/README.md](backend/README.md) 启动数据库、执行迁移和演示数据脚本。

在仓库根目录使用 Windows PowerShell 执行：

```powershell
cd frontend
npm.cmd ci
Copy-Item .env.example .env
npm.cmd run dev
```

启动成功后，以终端显示的地址为准，通常是 `http://127.0.0.1:5173/`。后端不可用时，真实查询、认证、发布和个人管理会显示连接错误。停止服务时在终端按 `Ctrl+C`。

## 检查与验证记录

以下命令在 `frontend/` 目录执行，按改动范围选择；生产构建在交付或相关配置变更时执行：

```powershell
npm.cmd test
npm.cmd run type-check
npm.cmd run build
```

`test` 运行现有 Vitest 接口层测试，`type-check` 检查 Vue/TypeScript 类型，`build` 执行类型检查并生成 `frontend/dist/`。`dist/` 只是本地产物，不提交到 Git。

如果 PowerShell 提示禁止运行 `npm.ps1`，请使用上述 `npm.cmd` 命令，无需修改系统执行策略。
