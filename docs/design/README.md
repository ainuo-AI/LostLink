## 首页用户流程

1. 用户打开根路径，等待后端返回当前页公开记录。
2. 用户可输入物品名称、地点或特征，点击搜索后更新结果。
3. 用户可按类别、校区、时间和失物/拾物类型筛选。选择东丽校区后可继续选择北区或南区；宁河校区不继续细分。
4. 用户点击卡片或“查看详情”进入独立详情路由，查看类别、地点、时间和具体联系方式；可使用浏览器前进、后退和刷新。
5. 用户可从详情页返回首页，或进入举报提交页；失物和拾物记录均不显示认领按钮。
6. 如果没有结果，页面显示空状态，用户可清除筛选。

## 组件和视觉规范

- 主题色：深蓝 `#123b5a`、操作蓝 `#155b8f`、辅助绿 `#65d1bb`。
- 背景与表面：页面背景 `#f2f7fa`，卡片表面 `#ffffff`，分隔线 `#d5e3ec`。
- 字体：优先使用 Noto Sans SC，加载失败时回退到 Microsoft YaHei 和无衬线字体。
- 状态标签：失物使用蓝色，拾物使用绿色。
- 首页和个人记录卡片使用第一张上传照片作为缩略图，裁剪填满图片区域；详情页按比例展示同一张照片。没有照片或加载失败时显示分类图标，校区标签始终保留。
- 桌面端为“左侧筛选 + 右侧结果”；低于 `1080px` 时卡片从三列改为两列。
- 低于 `820px` 时隐藏桌面导航，筛选面板改为按钮展开；低于 `560px` 时首页卡片改为单列。
- 手机导航与桌面端共享首页、发布失物、登记拾物、匹配通知、“我的”和登录入口；登录成功后隐藏重复的登录入口。表单、通知卡片和候选对比在窄屏改为单列。

## 新增页面交互

- 发布与拾物登记表单共用字段与图片组件。东丽校区要求北区或南区，切到宁河校区后区域字段消失且清空；发生地点使用按校区和区域筛选的下拉选项。拾物另需选择保管方式和同校区的保管地点。个人记录编辑也使用地点选项。时间不得晚于当前时间。
- 必填和错误提示显示在字段附近；提交失败保留输入并聚焦第一个错误。图片可预览、查看大图、移除或重选，支持 JPG、PNG、WebP，每张不超过 5MB、最多 3 张；发布时上传并关联。
- 有内容时重置需确认，未提交就离开页面会提示；提交中禁用重复提交。成功页展示服务器记录编号和“进行中”状态，并提供继续填写、返回首页操作。
- 注册成功后返回登录页；登录成功建立当前标签页会话，并返回原受保护页面。关闭标签页、会话失效或主动退出后需要重新登录。
- “我的”页面只读取当前用户的记录；编辑、完成和关闭操作仍由后端校验记录归属和状态转换。
- 通知按时间倒序展示，可筛选已读与处理状态、单条或全部标已读、加载更多。打开详情会标记已读；不提供确认匹配操作；拒绝前需确认，拒绝必须填写原因，可补充说明，已处理记录不可重复操作。
- 匹配详情显示双方名称、类别、描述、地点、时间、联系方式及照片或分类图标，综合分和维度说明来自服务端。规则匹配与可选图文模型的评估和降级范围见 [图文匹配说明](../api/multimodal-matching.md)。得分不是找回概率；用户直接联系对方，交接后由发布者标记找回或归还。

## 页面状态

| 状态 | 当前支持 | 说明 |
| --- | --- | --- |
| 默认列表 | 是 | 展示后端返回的当前页记录 |
| 搜索/筛选结果 | 是 | 将条件发送给后端并展示分页结果 |
| 空结果 | 是 | 提供清除筛选按钮 |
| 独立详情与举报 | 是 | 详情可通过 URL 恢复；举报写入服务端审核队列 |
| 发布及登记表单校验 | 是 | 显示字段错误、保留内容并聚焦首个错误；图片读取失败会阻止提交 |
| 服务端发布结果 | 是 | 展示服务器记录编号和进行中状态，个人页可继续管理 |
| 通知加载、筛选无结果与重试 | 是 | 区分通知为空、筛选无结果和读取失败 |
| 登录与无权限 | 是 | 发布、举报、通知和个人页要求登录；管理接口要求管理员角色 |
| 加载中 | 是 | 请求期间显示加载状态并禁用翻页 |
| 服务错误/离线/重试 | 是 | 展示后端错误或连接提示，并提供重试按钮 |
| 会话失效 | 是 | 清除当前标签页会话并引导重新登录 |

## 可访问性与隐私

已实现的可访问性内容：

- 搜索、导航、筛选和表单使用语义化标签和可读标签；字段错误使用 `role="alert"`。
- 卡片支持键盘 `Enter`；图片大图使用原生 `dialog`，支持 `Esc` 和关闭后焦点返回。
- 交互元素提供焦点样式，结果区使用 `aria-live`。
- 支持 `prefers-reduced-motion`，用户要求减少动画时缩短过渡。

已知缺口：还没有浏览器端自动化可访问性测试，新的表单与通知页面仍需正式键盘和屏幕阅读器回归。

本地表单可暂存用户输入的联系方式，草稿位于当前浏览器 `localStorage`；提交时完整联系方式写入后端，公开记录和匹配详情直接显示联系方式。图片发布前位于 IndexedDB，提交时上传服务器。不要在共享设备上留下真实联系方式或敏感物品信息；正式产品的可见范围、保存期限及删除机制仍待确认。
