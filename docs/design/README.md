## 首页用户流程

1. 用户打开根路径，查看全部演示记录。
2. 用户可输入物品名称、地点或特征，点击搜索后更新结果。
3. 用户可按类别、校区、时间和失物/拾物类型筛选。选择东丽校区后可继续选择北区或南区；宁河校区不继续细分。
4. 用户点击卡片或“查看详情”后打开弹窗，查看类别、地点、时间和联系提示。
5. 用户可点击关闭按钮、点击遮罩或按 `Esc` 关闭弹窗。
6. 如果没有结果，页面显示空状态，用户可清除筛选。

## 组件和视觉规范

- 主题色：深蓝 `#123b5a`、操作蓝 `#155b8f`、辅助绿 `#65d1bb`。
- 背景与表面：页面背景 `#f2f7fa`，卡片表面 `#ffffff`，分隔线 `#d5e3ec`。
- 字体：优先使用 Noto Sans SC，加载失败时回退到 Microsoft YaHei 和无衬线字体。
- 状态标签：失物使用蓝色，拾物使用绿色。
- 桌面端为“左侧筛选 + 右侧结果”；低于 `1080px` 时卡片从三列改为两列。
- 低于 `820px` 时隐藏桌面导航，筛选面板改为按钮展开；低于 `560px` 时卡片改为单列，弹窗改为上下布局。

## 可访问性与隐私

已实现的可访问性内容：

- 搜索、导航、筛选和弹窗使用语义化标签和可读标签。
- 卡片支持键盘 `Enter`，弹窗支持 `Esc`。
- 交互元素提供焦点样式，结果区使用 `aria-live`。
- 支持 `prefers-reduced-motion`，用户要求减少动画时缩短过渡。

已知缺口：详情弹窗尚未实现焦点锁定和关闭后的焦点恢复，后续引入可访问弹窗基础组件时需要补齐。

当前只使用虚构记录，没有真实姓名、联系方式、证件号、照片或上传数据。联系方式的展示和隐私规则尚未确认，不在当前原型中声称已实现。
