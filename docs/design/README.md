## 首页用户流程

1. 用户打开根路径，等待后端返回当前页演示记录。
2. 用户可输入物品名称、地点或特征，点击搜索后更新结果。
3. 用户可按类别、校区、时间和失物/拾物类型筛选。选择东丽校区后可继续选择北区或南区；宁河校区不继续细分。
4. 用户点击卡片或“查看详情”进入独立详情路由，查看类别、地点、时间和联系提示；可使用浏览器前进、后退和刷新。
5. 用户可从详情页返回首页，或进入举报提交页；认领按钮目前只显示未开放提示。
6. 如果没有结果，页面显示空状态，用户可清除筛选。

## 组件和视觉规范

- 主题色：深蓝 `#123b5a`、操作蓝 `#155b8f`、辅助绿 `#65d1bb`。
- 背景与表面：页面背景 `#f2f7fa`，卡片表面 `#ffffff`，分隔线 `#d5e3ec`。
- 字体：优先使用 Noto Sans SC，加载失败时回退到 Microsoft YaHei 和无衬线字体。
- 状态标签：失物使用蓝色，拾物使用绿色。
- 桌面端为“左侧筛选 + 右侧结果”；低于 `1080px` 时卡片从三列改为两列。
- 低于 `820px` 时隐藏桌面导航，筛选面板改为按钮展开；低于 `560px` 时首页卡片改为单列。
- 手机导航保留首页、发布失物、登记拾物和匹配通知四个入口；表单、通知卡片和候选对比在窄屏改为单列。

## 新增页面交互

- 发布与拾物登记表单共用字段与图片组件。东丽校区要求北区或南区，切到宁河校区后区域字段消失且清空；拾物另需选择保管方式并填写保管地点。时间不得晚于当前时间。
- 必填和错误提示显示在字段附近；提交失败保留输入并聚焦第一个错误。图片可预览、查看大图、移除或重选。暂定格式为 JPG、PNG、WebP，每张不超过 5MB、最多 3 张；这是前端演示规则，不是服务端上传契约。
- 有内容时重置需确认，未提交就离开页面会提示；提交中禁用重复提交。成功页展示 `demo-` 编号和待匹配本地状态，并提供继续填写、返回首页操作。
- 通知按时间倒序展示，可筛选已读与处理状态、单条或全部标已读、加载更多。打开详情会标记已读；确认与拒绝前需确认，拒绝可选原因并补充说明，已处理记录不可重复操作。
- 详情显示双方名称、类别、描述、地点、时间与无图占位，以及预设的综合分和维度说明。没有实物照片时图片维度显示“未评估”。模拟分数不是 AI 输出，也不是找回概率；确认仅接受候选，不代表完成认领或归还。

## 页面状态

| 状态 | 当前支持 | 说明 |
| --- | --- | --- |
| 默认列表 | 是 | 展示后端返回的当前页记录 |
| 搜索/筛选结果 | 是 | 将条件发送给后端并展示分页结果 |
| 空结果 | 是 | 提供清除筛选按钮 |
| 独立详情与举报 | 是 | 详情可通过 URL 恢复；举报只写当前浏览器 |
| 发布及登记表单校验 | 是 | 显示字段错误、保留内容并聚焦首个错误；图片读取失败会阻止提交 |
| 本地演示提交结果 | 是 | 本地编号和待匹配状态，不声称已写入服务器 |
| 通知加载、筛选无结果与重试 | 是 | 区分通知为空、筛选无结果和读取失败 |
| 未开放导航提示 | 是 | “我的”及认领动作明确说明未实现 |
| 加载中 | 是 | 请求期间显示加载状态并禁用翻页 |
| 服务错误/离线/重试 | 是 | 展示后端错误或连接提示，并提供重试按钮 |
| 无权限 | 否 | 待认证和权限要求确认后设计 |

## 可访问性与隐私

已实现的可访问性内容：

- 搜索、导航、筛选和表单使用语义化标签和可读标签；字段错误使用 `role="alert"`。
- 卡片支持键盘 `Enter`；图片大图使用原生 `dialog`，支持 `Esc` 和关闭后焦点返回。
- 交互元素提供焦点样式，结果区使用 `aria-live`。
- 支持 `prefers-reduced-motion`，用户要求减少动画时缩短过渡。

已知缺口：还没有浏览器端自动化可访问性测试，新的表单与通知页面仍需正式键盘和屏幕阅读器回归。

本地表单可暂存用户输入的联系方式，草稿位于当前浏览器 `localStorage`；提交后的公开演示记录只保存脱敏联系方式。图片位于 IndexedDB，不会上传服务器。不要在课程演示中填写真实联系方式或敏感物品信息；正式产品的可见范围、保存期限及删除机制仍待确认。
