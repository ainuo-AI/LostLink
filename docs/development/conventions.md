# 项目约定

## 命名

- Python 文件与函数使用 `snake_case`。
- Vue 组件使用 `PascalCase`。
- TypeScript 变量与函数使用 `camelCase`。
- 常量使用 `UPPER_SNAKE_CASE`。
- API 路径使用小写复数名词和连字符。

## 文档

- 面向团队的说明优先使用中文。
- 代码标识符、接口字段和提交类型使用英文。
- 重要设计决策记录背景、选择、理由和影响。
- 文档中的示例不得包含真实密钥或个人数据。

## 依赖

- 新增依赖前说明用途和替代方案。
- 前后端分别锁定依赖版本。
- 禁止把本地环境目录提交到仓库。

## 安全

- 密钥只通过环境变量或安全配置注入。
- 上传文件、日志和数据库备份不进入 Git。
- 外部服务失败时必须保留明确的错误处理和降级策略。
