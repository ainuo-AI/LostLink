# Frontend

前端计划采用 Vue 3。

当前目录只定义代码组织方式，不包含页面、组件、路由、状态管理或请求实现。

## 目录职责

- `src/api/`：后端接口访问封装
- `src/assets/`：需要参与构建的静态资源
- `src/components/`：通用组件
- `src/layouts/`：页面布局
- `src/router/`：路由配置
- `src/stores/`：全局状态
- `src/styles/`：全局样式与设计变量
- `src/types/`：共享类型
- `src/views/`：页面级视图
- `public/`：不参与构建处理的公共资源
- `tests/`：前端测试
